# Mushak-Vinayaka

A 2D top-down action-adventure browser game for Ganesh Chaturthi: **Mushak & Vinayaka: The Vahana's Journey**.

Play as Mushak and Vinayaka on their journey to Gajamukhasura.

## How to Play

Open `index.html` directly in any web browser, or run a local HTTP server:

```bash
python -m http.server 3000
```

Then visit: [http://localhost:3000](http://localhost:3000)

## Controls

- **Movement:** `W`, `A`, `S`, `D` or Arrow keys (or virtual joystick on mobile)
- **Dash:** `Space`
- **Strike:** `J`
- **Divine Light:** `K`
- **Mushak Assist:** `L`
